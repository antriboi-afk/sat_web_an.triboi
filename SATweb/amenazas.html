Amenazas informáticas

Conoce los ataques, el malware y las técnicas que pueden poner en peligro tus datos.

¿Qué es el malware?

Malware es el término general utilizado para referirse al software malicioso diseñado para robar información, dañar equipos, espiar a usuarios o permitir accesos no autorizados.

Sus efectos pueden afectar a la confidencialidad, la integridad y la disponibilidad de un sistema.

Ingeniería social

Phishing (suplantación)

Es una estafa que utiliza correos, mensajes o páginas falsas que parecen pertenecer a entidades legítimas para conseguir contraseñas, datos bancarios u otra información confidencial.

Ejemplo: un mensaje falso del banco que solicita confirmar la contraseña mediante un enlace.

Prevención: comprobar el dominio, evitar enlaces sospechosos y acceder a la web oficial directamente.

Disponibilidad

Ataque DoS y DDoS

Un ataque DoS intenta dejar un servicio fuera de funcionamiento mediante una sobrecarga de peticiones o el agotamiento de sus recursos. En un DDoS intervienen numerosos dispositivos distribuidos.

Ejemplo: una página web deja de responder porque recibe más solicitudes de las que puede atender.

Prevención: filtrado de tráfico, monitorización y servicios de mitigación de DDoS.

Malware

Troyano

Es un programa malicioso que se presenta como si fuera legítimo. Al ejecutarlo, puede instalar malware, robar datos o permitir que otra persona controle el equipo.

A diferencia de un gusano, un troyano no se caracteriza por autorreplicarse automáticamente.

Prevención: descargar programas de fuentes fiables, actualizar el sistema y utilizar protección antimalware.

Acceso no autorizado

Backdoors o puertas traseras

Son mecanismos que permiten acceder a un sistema evitando algunos controles normales de autenticación. Pueden ser instalados por malware o existir por errores de configuración.

Una puerta trasera puede permitir que un atacante vuelva a entrar después de haber comprometido el equipo.

Prevención: revisar accesos, cerrar servicios innecesarios y mantener los equipos actualizados.

Espionaje

Spyware

Es un programa que recopila información sobre el equipo o las actividades del usuario sin su conocimiento o consentimiento adecuado.

Puede recopilar hábitos de navegación, información personal y otros datos sensibles.

Prevención: revisar permisos, evitar descargas dudosas y utilizar herramientas de seguridad.

Robo de información

Stealers

Son programas maliciosos especializados en robar información almacenada en un dispositivo, como credenciales guardadas, cookies de sesión, datos del navegador o carteras de criptomonedas.

La información robada puede utilizarse para acceder a cuentas o cometer fraudes.

Prevención: utilizar autenticación multifactor, actualizar el equipo y no ejecutar archivos sospechosos.

Malware histórico

Koobface

Koobface fue una familia de malware que se propagó mediante redes sociales y mensajes que parecían proceder de amigos. Sus campañas utilizaban enlaces engañosos y descargas maliciosas para infectar equipos.

Los dispositivos infectados podían convertirse en parte de una red controlada por los atacantes.

Lección: no confiar automáticamente en enlaces enviados por contactos conocidos.

Red de equipos infectados

Botnet

Es una red de ordenadores o dispositivos infectados que un ciberdelincuente controla de forma remota. Cada dispositivo comprometido puede actuar como un ordenador zombi.

Las botnets se utilizan para enviar spam, distribuir malware, robar información y realizar ataques DDoS.

Síntomas posibles: conexión lenta, actividad de red desconocida o mensajes enviados sin permiso. Estos síntomas por sí solos no confirman una infección.

Prevención: actualizar dispositivos, utilizar cortafuegos y evitar software de procedencia dudosa.

Contraseñas

Ataque de fuerza bruta

Consiste en intentar numerosas combinaciones de contraseñas hasta encontrar la correcta. El ataque de diccionario es una variante que prueba palabras y claves comunes.

Las contraseñas largas y únicas dificultan estos ataques. También es importante limitar los intentos de acceso.

Prevención: utilizar contraseñas robustas, un gestor de contraseñas y autenticación multifactor.

Control del sistema

Rootkit

Es un conjunto de herramientas maliciosas diseñado para ocultar la presencia de un atacante o de otros componentes maliciosos dentro de un sistema.

Prevención: mantener el sistema actualizado y analizar incidentes con herramientas de seguridad fiables.

Extorsión

Ransomware

Es un tipo de malware que cifra archivos o bloquea el acceso a un sistema y exige un rescate para intentar recuperarlo.

Pagar no garantiza recuperar los datos. Las copias de seguridad aisladas son esenciales para la recuperación.

Propagación

Gusanos informáticos

Son programas capaces de replicarse y propagarse entre equipos, por ejemplo, aprovechando vulnerabilidades de red. Pueden consumir recursos e instalar otras amenazas.

Prevención: aplicar actualizaciones, utilizar cortafuegos y analizar archivos sospechosos.

Otras amenazas que debemos conocer

  • Adware: software que muestra publicidad no deseada.
  • Keylogger: programa que registra las pulsaciones del teclado.
  • Pharming: técnica que redirige al usuario hacia páginas fraudulentas.
  • Spam: mensajes no solicitados enviados masivamente.
  • Exploit: código o técnica que aprovecha una vulnerabilidad.
  • Bug: error de software que puede causar fallos y, en algunos casos, vulnerabilidades.
  • Hoax: bulo o falsa alerta que se difunde entre usuarios.
  • Hijacker: software que modifica el navegador o sus redirecciones sin permiso.

¿Qué hacer ante una posible infección?

  1. Desconectar el dispositivo de la red si hay indicios de actividad maliciosa.
  2. No introducir contraseñas desde el equipo sospechoso.
  3. Analizar el dispositivo con herramientas de seguridad fiables.
  4. Cambiar las contraseñas desde un dispositivo limpio y cerrar sesiones abiertas.
  5. Restaurar los datos desde copias de seguridad seguras cuando corresponda.

En un equipo de empresa o del centro educativo, avisa al responsable informático antes de eliminar archivos o modificar el sistema, especialmente si hay que investigar el incidente.
